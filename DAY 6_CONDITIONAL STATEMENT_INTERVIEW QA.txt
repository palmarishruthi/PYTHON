🐍 Python Conditional Statements – 20 Interview Questions & Answers
1. What is a conditional statement in Python? Why do we use conditional statements?

A conditional statement allows Python to make decisions based on whether a condition is True or False.

We use conditional statements when we want different code to execute depending on a situation.

Example:
age = 20

if age >= 18:
    print("Eligible to vote")

Output:

Eligible to vote

Here, Python checks age >= 18. Since it is True, the print() statement executes.

4. How does an if statement work in Python?

The if statement evaluates a condition.

If the condition is True, the if block executes.
If the condition is False, the if block is skipped.
Example:
age = 25

if age >= 18:
    print("Eligible")
Flow:
       age >= 18?
          |
     ┌────┴────┐
    True     False
     |          |
 Execute      Skip
     |
 "Eligible"
5. What happens when the condition in an if statement evaluates to False?

When the condition is False, Python does not execute the statements inside the if block.

Example:
age = 15

if age >= 18:
    print("Eligible")

Since 15 >= 18 is False, nothing is printed.

If an else block is present, the else block executes.

age = 15

if age >= 18:
    print("Eligible")
else:
    print("Not Eligible")

Output:

Not Eligible
6. What is the purpose of the else block in Python?

The else block executes when the preceding condition is False.

Example:
number = 7

if number % 2 == 0:
    print("Even")
else:
    print("Odd")

Output:

Odd
Simple idea:
Condition
   |
 ┌─┴─┐
True False
 |     |
if    else
7. When should you use if-else instead of only if?

Use if-else when you need to perform one action if the condition is True and another action if it is False.

Only if:
age = 20

if age >= 18:
    print("Adult")

If the condition is false, nothing happens.

if-else:
age = 15

if age >= 18:
    print("Adult")
else:
    print("Minor")

Here, both possibilities are handled.

8. What is an elif statement? How is it different from multiple independent if statements?

elif means "else if".

It is used when there are multiple conditions to check.

Using elif:
marks = 75

if marks >= 90:
    print("A")
elif marks >= 60:
    print("B")
elif marks >= 40:
    print("C")
else:
    print("Fail")

Only one block is executed.

Multiple independent if statements:
marks = 75

if marks >= 40:
    print("Pass")

if marks >= 60:
    print("Good")

if marks >= 90:
    print("Excellent")

Each if is checked independently.

Key difference:

if-elif-else → mutually exclusive decision chain

Multiple if → every condition is checked independently

9. How does Python evaluate conditions in an if-elif-else ladder?

Python evaluates conditions from top to bottom.

marks = 75

if marks >= 90:
    print("A")
elif marks >= 60:
    print("B")
elif marks >= 40:
    print("C")
else:
    print("Fail")

Python checks:

marks >= 90  → False
      ↓
marks >= 60  → True
      ↓
Execute B
      ↓
Stop checking remaining elif conditions

So the output is:

B
10. If multiple conditions in an if-elif-else ladder are True, which block will Python execute? Why?

Python executes the first condition that evaluates to True.

Example:
number = 10

if number > 5:
    print("First")
elif number > 8:
    print("Second")
elif number > 9:
    print("Third")

All three conditions are technically True.

But output is:

First
Why?

Because Python evaluates from top to bottom and stops after finding the first True condition.

11. What is a nested if statement in Python? When would you use it?

A nested if means an if statement placed inside another if statement.

Example:
age = 25
has_id = True

if age >= 18:
    if has_id:
        print("Entry allowed")

Here:

Outer if
   ↓
age >= 18?
   ↓ True
Inner if
   ↓
has_id?
   ↓ True
Entry allowed
When do we use it?

When a second condition should be checked only after the first condition is satisfied.

13. In a nested if, when will the inner condition be checked?

The inner condition is checked only when the outer condition is True.

Example:
age = 15
has_id = True

if age >= 18:
    if has_id:
        print("Entry allowed")

First:

age >= 18 → False

Therefore, Python does not check the inner if.

14. What happens to the inner if condition when the outer if condition is False?

When the outer condition is False, Python skips the entire outer block, including the inner if.

Example:
age = 15

if age >= 18:
    if age >= 21:
        print("Allowed")

Since:

age >= 18 → False

Python doesn't evaluate:

age >= 21

The inner condition is skipped.

15. What is the difference between = and == when writing conditions in Python?

This is a very common interview question.

=

= is the assignment operator.

It assigns a value to a variable.

age = 25
==

== is the equality comparison operator.

It checks whether two values are equal.

age == 25
Example:
age = 25

if age == 25:
    print("Age is 25")

Output:

Age is 25
Remember:
=   → Assign
==  → Compare
16. Why is indentation important in Python conditional statements?

Python uses indentation to define blocks of code.

Unlike languages such as C or Java, Python doesn't use { } to define blocks.

Correct:
age = 20

if age >= 18:
    print("Adult")
Incorrect:
age = 20

if age >= 18:
print("Adult")

This produces an IndentationError.

Simple rule:
if condition:
    ← indented block
    statement
    statement

Usually, 4 spaces are used for indentation.

17. What is the purpose of the colon (:) after if, elif, else, match, and case?

The colon : indicates that a new block of code begins.

Example:
if age >= 18:
    print("Adult")

The colon after if age >= 18 tells Python:

"The statements belonging to this if block come next."

Similarly:

if condition:
    ...

elif condition:
    ...

else:
    ...

For match-case:

match day:
    case 1:
        print("Monday")

The colon marks the beginning of the corresponding block.

19. Explain how and, or, and not can be used inside conditional statements.
and

Returns True when both conditions are True.

age = 25
salary = 50000

if age >= 18 and salary >= 30000:
    print("Eligible")
True AND True = True
True AND False = False
or

Returns True when at least one condition is True.

age = 17

if age < 18 or age > 60:
    print("Special category")
True OR False = True
False OR False = False
not

Reverses the Boolean result.

is_raining = False

if not is_raining:
    print("Go outside")

Since is_raining is False:

not False → True

Therefore, the statement executes.

Easy way to remember:
AND → Both must be True
OR  → At least one must be True
NOT → Reverses True/False
20. What is the difference between using if-elif-else and match-case?

Both can be used for decision-making, but they are designed for somewhat different situations.

if-elif-else

Best when conditions involve comparisons, ranges, or complex Boolean expressions.

marks = 75

if marks >= 90:
    print("A")
elif marks >= 60:
    print("B")
else:
    print("C")
match-case

Introduced in Python 3.10, match-case is useful for structural pattern matching and matching a value against specific patterns.

day = 2

match day:
    case 1:
        print("Monday")
    case 2:
        print("Tuesday")
    case 3:
        print("Wednesday")
    case _:
        print("Invalid day")

Output:

Tuesday
Main difference:
if-elif-else	match-case
General conditional logic	Pattern matching
Excellent for ranges	Excellent for specific patterns/values
Supports complex Boolean conditions	Supports structural patterns
Available in older Python versions	Introduced in Python 3.10
Interview answer:

if-elif-else is generally used for conditions, comparisons, ranges, and complex Boolean logic, whereas match-case is used for structural pattern matching and matching values against specific patterns.

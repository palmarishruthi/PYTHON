Python Introduction – Questions & Answers
1. What is Python?

Python is a high-level, interpreted, general-purpose programming language.

It is known for its:

Simple and readable syntax
Large number of libraries
Easy learning curve
Support for multiple programming paradigms
Wide range of applications

Example:

print("Hello World")

Python is commonly used in Data Engineering, Data Science, Machine Learning, Web Development, Automation, and Software Development.

2. Who created Python and when was it released?

Python was created by Guido van Rossum.

Development started: 1989
First public release: 1991
Python was developed as a successor to the ABC programming language.
Guido van Rossum continued as Python's lead developer for many years.

The name Python was inspired by the British comedy show "Monty Python's Flying Circus", rather than the snake.

3. Why is Python considered a high-level language?

Python is called a high-level programming language because it allows programmers to write instructions using human-readable syntax without worrying about low-level computer operations such as memory addresses and CPU instructions.

For example:

a = 10
b = 20
print(a + b)

We don't need to manually manage memory or convert these instructions into machine code.

Advantages of high-level languages:
Easy to understand
Easy to write
Easy to maintain
Faster development
Less code compared with low-level languages

7. Explain the Python Architecture with a diagram.

A simplified Python architecture can be represented as:

             Python Source Code
                    |
                    ↓
              Python Parser
                    |
                    ↓
             Bytecode (.pyc)
                    |
                    ↓
       Python Virtual Machine (PVM)
                    |
                    ↓
            Machine Instructions
                    |
                    ↓
               Operating System
                    |
                    ↓
                  CPU
Explanation:

1. Python Source Code

The programmer writes Python code in a .py file.

Example:

print("Hello")

2. Parser

Python checks the syntax and converts the source code into an internal representation.

3. Bytecode

Python converts the code into bytecode.

Bytecode is an intermediate representation that is not directly the machine code of a particular CPU.

4. Python Virtual Machine (PVM)

The PVM executes the Python bytecode.

5. Operating System and CPU

The underlying system ultimately performs the required operations.

Note: The exact implementation details vary between Python implementations. The above diagram is a simplified model commonly used for understanding Python execution.

8. What is the role of the Python Virtual Machine (PVM)?

PVM stands for Python Virtual Machine.

Its main responsibility is to execute Python bytecode.

The basic flow is:

Python Code
     ↓
Bytecode
     ↓
PVM
     ↓
Execution

For example:

x = 10
y = 20
print(x + y)

Python internally converts the program into bytecode, and the PVM executes that bytecode.

Important point:

The PVM is not a physical machine.

It is a software component of a Python implementation that provides the environment for executing Python bytecode.

9. Differentiate between a Compiler and an Interpreter.
Compiler	Interpreter
Translates source code before execution	Executes code through an interpreter/runtime
Traditionally translates an entire program or compilation unit	Traditionally executes instructions progressively
Produces compiled output in many compiled languages	Usually doesn't produce a standalone machine-code executable as the direct result
Compilation can take time before execution	Often starts execution more directly
Examples: C, C++	Python, Ruby
Important Python clarification

Python is commonly called an interpreted language, but Python implementations also perform compilation to bytecode.

For example:

Python Source Code
       ↓
Compilation to Bytecode
       ↓
Python Virtual Machine
       ↓
Execution

So saying simply "Python has no compilation" is not technically accurate.

11. What is a Virtual Environment, and why is it needed?

A Virtual Environment is an isolated Python environment used to install project-specific packages separately from other projects.

Why do we need it?

Suppose you have two projects:

Project A → Pandas 1.x
Project B → Pandas 2.x

Installing everything globally can create dependency conflicts.

A virtual environment keeps the dependencies separate.

Create a virtual environment:
python -m venv myenv
Activate on Windows:
myenv\Scripts\activate
Activate on Linux/macOS:
source myenv/bin/activate

Then install packages:

pip install pandas

The structure becomes:

Computer
   |
   ├── Project A
   │      └── Virtual Environment A
   │             └── Pandas version A
   |
   └── Project B
          └── Virtual Environment B
                 └── Pandas version B
Main benefit:

Virtual environments prevent dependency conflicts between projects.

12. What is pip? Write four commonly used pip commands.

pip is the standard package-management tool commonly used to install and manage Python packages.

For example:

pip install pandas

installs the Pandas package.

Four commonly used pip commands:

1. Install a package

pip install pandas

2. Uninstall a package

pip uninstall pandas

3. Show installed packages

pip list

4. Upgrade a package

pip install --upgrade pandas

Another useful command is:

pip freeze

It displays installed packages and their versions, which can be redirected to a requirements file:

pip freeze > requirements.txt
13. Explain the Python execution flow.

Python execution can be understood as:

Python Program (.py)
        ↓
Python Interpreter
        ↓
Syntax / Parsing
        ↓
Bytecode
        ↓
Python Virtual Machine
        ↓
Execution
        ↓
Output

Let's take an example:

a = 10
b = 20


result = a + b


print(result)
Step 1 – Write source code

The programmer writes the code in a .py file.

Step 2 – Python reads the code

The Python implementation parses the source and checks its syntax.

Step 3 – Bytecode generation

The source is compiled into Python bytecode.

Step 4 – PVM executes bytecode

The Python Virtual Machine executes the bytecode.

Step 5 – Output

The result is displayed:

30
Simple flow to remember:

Source Code → Bytecode → PVM → Output

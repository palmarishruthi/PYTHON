🐍 Python Loops – Interview Questions & Answers
1. What is a loop in Python? Why do we use loops?

A loop is used to execute a block of code repeatedly.

Instead of writing the same code multiple times, we use a loop to perform the same operation automatically.

Example without loop:
print(1)
print(2)
print(3)
print(4)
print(5)
Using a loop:
for i in range(1, 6):
    print(i)

Output:

1
2
3
4
5
Why do we use loops?

Loops are useful when:

We need to repeat a task.
We need to process multiple values.
We need to iterate through a list, tuple, string, etc.
We don't want to write repetitive code.
Interview answer:

A loop is a control structure that repeatedly executes a block of code until a specified condition is satisfied or the sequence is exhausted.

2. What is the difference between for loop and while loop?

Python mainly provides two types of loops:

for
while
for loop

A for loop is generally used when we want to iterate over a sequence or iterable.

for i in range(5):
    print(i)
while loop

A while loop is used when we want to repeatedly execute code as long as a condition is True.

i = 1

while i <= 5:
    print(i)
    i += 1
Difference:
for loop	while loop
Used to iterate over an iterable	Used based on a condition
Common when the iteration is known or sequence-based	Useful when the stopping condition depends on changing state
Automatically moves to the next item	We usually need to update the condition variable
Example: list, tuple, string, range()	Example: run until user enters a valid value
Easy way to remember:
for    → Iterate
while  → Condition
3. When would you choose a for loop instead of a while loop?

Choose a for loop when you want to iterate over a sequence or iterable, or when the number of iterations can naturally be determined.

Example:

Suppose we have a list of students:

students = ["Asha", "Ravi", "John"]

for student in students:
    print(student)

Here, for is a natural choice because we are iterating through a list.

Another example:
for i in range(1, 11):
    print(i)

We know we want to iterate from 1 to 10.

Interview answer:

I prefer a for loop when I need to iterate over an iterable such as a list, tuple, string, dictionary, or range, especially when the iteration pattern is known.

4. What happens if the condition of a while loop never becomes False?

If the condition never becomes False, the while loop continues executing indefinitely.

This is called an infinite loop.

Example:
i = 1

while i <= 5:
    print(i)

Here, i is never increased.

Therefore:

i = 1
i = 1
i = 1
i = 1
...

The condition:

i <= 5

always remains True.

Correct version:
i = 1

while i <= 5:
    print(i)
    i += 1

Now i eventually becomes 6, so the condition becomes False.

5. What is an infinite loop? Give an example.

An infinite loop is a loop that continues executing forever because its termination condition is never reached.

Example:
while True:
    print("Hello")

Since:

True

is always True, the loop never ends by itself.

Another example:
i = 1

while i <= 5:
    print(i)

The variable i never changes, so the condition remains True.

How can we stop an infinite loop?

We can use break when an appropriate condition is reached:

i = 1

while True:
    print(i)

    if i == 5:
        break

    i += 1

Output:

1
2
3
4
5
6. What is the purpose of range() in a for loop?

range() generates a sequence of numbers that can be iterated over.

It is commonly used with for loops.

Example:
for i in range(5):
    print(i)

Output:

0
1
2
3
4

Notice that 5 is not included.

range() can take:
range(stop)
range(start, stop)
range(start, stop, step)

For example:

range(1, 6)

generates:

1 2 3 4 5
Interview answer:

range() is used to generate a sequence of numbers, commonly for controlling the number or pattern of iterations in a for loop.

7. Explain the difference between range(5), range(1, 5), and range(1, 10, 2).

This is a very important interview question.

range(5)

Starts from 0 and stops before 5.

for i in range(5):
    print(i)

Output:

0
1
2
3
4
range(1, 5)

Starts from 1 and stops before 5.

for i in range(1, 5):
    print(i)

Output:

1
2
3
4
range(1, 10, 2)

Starts at 1, stops before 10, and increases by 2.

for i in range(1, 10, 2):
    print(i)

Output:

1
3
5
7
9
Remember:
range(start, stop, step)
       ↓      ↓     ↓
      Start  End   Jump

Important: The stop value is excluded.

8. What is a nested loop? Explain with a real-world example.

A nested loop is a loop inside another loop.

Example:
for i in range(3):
    for j in range(2):
        print(i, j)

The inner loop executes completely for each iteration of the outer loop.

Output:
0 0
0 1
1 0
1 1
2 0
2 1
Real-world example: Classrooms and students

Imagine:

A school has 3 classrooms.
Each classroom has 2 students.
We want to visit every student in every classroom.
Classroom 1
   ↓
Student 1
Student 2

Classroom 2
   ↓
Student 1
Student 2

Classroom 3
   ↓
Student 1
Student 2

The outer loop represents classrooms.

The inner loop represents students.

Common applications:

Nested loops are commonly used for:

Matrix processing
Tables
Patterns
Comparing elements
Processing rows and columns
🔄 Loop Control Statements

Python provides several statements that control loop execution:

break
continue
pass
9. What is the difference between break, continue, and pass?

This is one of the most important loop interview questions.

Statement	Purpose
break	Completely terminates the loop
continue	Skips the current iteration
pass	Does nothing; acts as a placeholder
break

Stops the loop completely.

for i in range(1, 6):

    if i == 3:
        break

    print(i)

Output:

1
2

When i == 3, the loop terminates.

continue

Skips the current iteration and moves to the next iteration.

for i in range(1, 6):

    if i == 3:
        continue

    print(i)

Output:

1
2
4
5

3 is skipped.

pass

Does nothing.

for i in range(5):

    if i == 3:
        pass

    print(i)

Output:

0
1
2
3
4

pass does not skip the iteration or stop the loop.

Easy memory trick:
break     → STOP
continue  → SKIP
pass      → DO NOTHING
10. What happens when Python encounters a break statement inside a nested loop?

A break statement terminates the nearest enclosing loop in which it appears.

It does not automatically terminate all outer loops.

Example:
for i in range(3):

    for j in range(3):

        if j == 1:
            break

        print(i, j)
Output:
0 0
1 0
2 0

Here, break stops the inner loop only.

The outer loop continues.

Important:
Outer loop
   ↓
Inner loop
   ↓
break
   ↓
Stops INNER loop
   ↓
Outer loop continues

This is a very common interview point.

12. Why do we use pass when it does nothing?

pass is used as a placeholder when Python requires a statement syntactically, but we don't want to execute any action yet.

Example:
if age >= 18:
    pass
else:
    print("Minor")

The pass tells Python:

"I intentionally don't want to do anything here for now."

Common use:

When developing a program, we may create a function or class but implement it later.

def calculate_salary():
    pass

The function can exist without causing a syntax error.

Later, we can replace pass with the actual implementation.

Important interview point:

pass does not:

Stop the loop ❌
Skip the iteration ❌
Exit the program ❌

It simply does nothing.
